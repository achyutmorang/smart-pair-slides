\section{Literature Survey}

\begin{frame}{Signal Families in Prior Work}
\begin{itemize}
    \item \textbf{Risk/criticality metrics:} TTC, collision proxies, near-miss severity.
    \item \textbf{Distribution mismatch:} OOD detection, novelty scores, rarity measures.
    \item \textbf{Planner uncertainty:} predictive entropy/divergence and confidence diagnostics.
\end{itemize}
\vspace{0.4em}
\begin{block}{Gap}
Conceptual validity of uncertainty signals is known; robustness as \emph{optimization targets} in practical closed-loop stacks is less established.
\end{block}
\end{frame}

\begin{frame}{From Idea-First to Benchmark-First}
\begin{itemize}
    \item Exploratory literature suggests surprise-like objectives can identify informative scenarios.
    \item Benchmark literature emphasizes reproducibility, strong baselines, and protocol control.
    \item This thesis combines both:
    \begin{itemize}
        \item test broad uncertainty formulations first,
        \item then pivot to baseline-first WOSAC-aligned contribution.
    \end{itemize}
\end{itemize}
\end{frame}
